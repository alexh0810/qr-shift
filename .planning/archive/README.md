# Planning Archive

This directory keeps historical planning context that is no longer part of the active execution surface.

- `phases/` holds completed phase folders that still matter as reference material.
- `debug/` holds resolved or stale debug session notes.

Active planning should stay in:

- `.planning/phases/`
- `.planning/debug/`
- `.planning/notes/`

Archive rather than delete when the history is still useful but no longer needs to clutter the active planning tree.
