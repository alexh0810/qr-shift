## Brand personality

| Option | Description | Selected |
|--------|-------------|----------|
| Operational + confident | Clean, efficient, trustworthy, with some edge and less corporate feel | |
| Modern + bold | More startup-forward, punchier, and stronger as a first impression | ✓ |
| Calm + premium | Minimal, refined, quieter, and more upscale | |
| Custom | User-defined blend | |

**User's choice:** Modern + bold
**Notes:** The user wants QRShift to feel more memorable and product-like for demos rather than staying neutral or overly industrial.

## Typography direction

| Option | Description | Selected |
|--------|-------------|----------|
| Expressive headlines + clean body | Distinctive display tone for headings with readable UI/body typography | ✓ |
| All clean and neutral | One consistent modern sans system with lower visual personality | |
| Operational signage feel | More structured and utilitarian, like a signage or systems interface | |
| Custom | User-defined direction | |

**User's choice:** Expressive headlines + clean body
**Notes:** Brand moments should carry character, while operational screens remain easy to read and use.

## Surface and component language

| Option | Description | Selected |
